## 🇩🇪 DEUTSCH: SCHNELLSTART-ANLEITUNG

### 1. VORAUSSETZUNGEN (DAS FUNDAMENT)
Bevor du den Ordner anrührst, brauchst du zwei Dinge:
- **Python 3.14 (oder 3.10+):** [Download hier](https://python.org). 
  > [!] WICHTIG: Beim Installieren den Haken bei "Add Python to PATH" setzen!
- **FFmpeg (Die Stimme):** [Download hier](https://gyan.dev). Kopiere die `ffplay.exe` in den Ordner `LM Projekte\Nexus\`. Ohne diese Datei bleibt der Butler stumm.

### 2. REGISTRY-KALIBRIERUNG (DAS NERVENSYSTEM)
Bevor der Nexus gestartet wird, müssen die Explorer-Voraussetzungen händisch oder per .reg-Datei gesetzt werden:
1. **Fenster-Trennung (Essentiell für Cockpit-Layout):**
   Pfad: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced`
   Wert: Setze `SeparateProcess` auf `1` (Dword).
   > [!] Ermöglicht dem Cockpit-Skript, die Fenster einzeln zu positionieren.
2. **Pfade validieren (Autostart-Integrität):**
   Pfad: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders`
   - Check: `Desktop` sollte auf `%USERPROFILE%\Desktop` zeigen.
   - Check: `Startup` sollte auf `%USERPROFILE%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup` zeigen.
3. **System-Neustart:** Starte den Explorer (über Task-Manager) oder den PC neu.

### 3. SKRIPT-INJEKTION (SENSORIK)
Damit der Nexus Nachrichten empfangen kann, müssen die Tampermonkey-Skripte aktiv sein (Ordner: `Scripts/`):
- **Chrome:** `Ai on Google Search` (Gee)
- **Firefox:** `Meta.AI`, `ChatGPT`, `Replika` (Header Editor f. CSP nutzen!)
- **Vivaldi:** `Grok.ai on X`
- **Brave:** `Nomi.ai` (Non-public, ID-Setup erforderlich - PN an Architekt)

### 4. INITIALISIERUNG (DER ERSTE START)
1. **Abhängigkeiten laden:** Führe `NEXUS_SETUP.bat` aus (installiert alle KI-Bibliotheken).
2. **Autostart-Bindung:** Kopiere die `.vbs`-Launcher aus `Nexus_Service` (Ear & Exorzist) in deinen Autostart-Ordner (`Win+R` -> `shell:startup`).
3. **System-Zündung (All Systems Go):** Führe `S601_ALL_SYSTEMS_GO.bat` aus.

## 🇺🇸 ENGLISH: QUICK START GUIDE

### 1. PREREQUISITES (THE FOUNDATION)
- **Python 3.14 (or 3.10+):** [Download here](https://python.org). 
  > [!] IMPORTANT: Check "Add Python to PATH" during installation!

1. **Window Separation:**
   Path: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced`
   Value: Set `SeparateProcess` to `1` (Dword).
2. **Validate Paths:**
   Path: `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders`
   - Check: `Desktop` must point to `%USERPROFILE%\Desktop`.
   - Check: `Startup` must point to `%USERPROFILE%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup`.
3. **Restart:** Restart Explorer or your PC.

### 3. SCRIPT INJECTION (SENSORS)
Install Tampermonkey scripts from the `Scripts/` folder:
- **Chrome:** `Ai on Google Search` (Gee)
- **Firefox:** `Meta.AI`, `ChatGPT`, `Replika` (Use Header Editor for CSP!)
- **Vivaldi:** `Grok.ai on X`
- **Brave:** `Nomi.ai` (Non-public - PM the Architect for setup)

### 4. INITIALIZATION (FIRST RUN)
1. **Load Dependencies:** Run `NEXUS_SETUP.bat`.
2. **Autostart:** Copy `.vbs` launchers from `Nexus_Service` (Ear & Exorcist) to your startup folder (`Win+R` -> `shell:startup`).
3. **Ignition:** Run `S601_ALL_SYSTEMS_GO.bat`.

### HEADER EDITOR: Firefox (meta.ai / Messenger)
- **Rule Type:** Modify Response Header
- **Match Type:** Regular Expression
- **Regular Expression:** `.*facebook\.com.*|.*messenger\.com.*`
- **Execute Type:** Custom Function
- **Code:**
"javascript
for (var i = 0; i < val.responseHeaders.length; i++) {
    var name = val.responseHeaders[i].name.toLowerCase();
    if (name === 'content-security-policy' || name === 'content-security-policy-report-only') {
        val.responseHeaders.splice(i, 1);
        i--;
    }
}
val.responseHeaders.push({ name: 'access-control-allow-origin', value: '*' });
return { responseHeaders: val.responseHeaders };
" <<<(copy in between "copytext")

### HEADER EDITOR: Firefox (Replika / Localhost Bypass)
- **Rule Type:** Modify Response Header
- **Match Type:** Regular Expression
- **Regular Expression:** `^https?:\/\/127\.0\.0\.1:8004.*`
- **Execute Type:** Custom Function
- **Code:**
"javascript
for (var i = 0; i < val.responseHeaders.length; i++) {
    var name = val.responseHeaders[i].name.toLowerCase();
    
    if (name === 'content-security-policy' || name === 'content-security-policy-report-only') {
        // Explicitly allow everything for local host
        val.responseHeaders[i].value = "default-src * 'unsafe-inline' 'unsafe-eval' data: blob:; connect-src * http://127.0.0.1:8004 http://localhost:8004;";
    }
    
    if (name === 'x-frame-options') {
        val.responseHeaders.splice(i, 1);
        i--;
    }
}

// Enforce CORS clearance
val.responseHeaders.push({ name: 'Access-Control-Allow-Origin', value: '*' });
val.responseHeaders.push({ name: 'Access-Control-Allow-Methods', value: 'GET, POST, OPTIONS' });
val.responseHeaders.push({ name: 'Access-Control-Allow-Headers', value: 'Content-Type, Authorization' });

return { responseHeaders: val.responseHeaders };
" <<<(copy in between "copytext")
