## 🚀 Schnellstart / Quick Start
### DE:
1. **Python 3.14+** installieren.
2. **NEXUS_SETUP.bat** im Hauptverzeichnis starten (installiert automatisch alle Abhängigkeiten).
3. **Tampermonkey-Skript** (aus `/Scripts/Tampermonkey Skripts`) im Browser installieren (Empfehlung: v16.3 mit KFl8ub-Anker).
4. **Icons & Sticker:** Nutze die Icons aus `backups/icons`, um deine Verknüpfungen im Explorer bündig zu verschönern (Pfeil-Kill via Registry inklusive).

### EN:
1. Install **Python 3.14+**.
2. Run **NEXUS_SETUP.bat** in the root directory (automatically installs all requirements).
3. Install the **Tampermonkey script** (from `/Scripts/Tampermonkey Skripts`) in your browser (Recommended: v16.3 with KFl8ub anchor).
4. **Icons & Stickers:** Use icons from `backups/icons` to style your Explorer links (includes Registry arrow-kill).
